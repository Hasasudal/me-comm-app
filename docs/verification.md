# 검증 기록

## 완료한 검증

- TypeScript 검사 통과.
- 웹 빌드 통과. 이후 변경분은 최종 빌드에서 다시 확인합니다.
- 실제 로컬 D1 저장소로 통합 API 테스트 통과.
  - 자유게시판, 뉴스, 동아리, 공모전 글 생성
  - 목록에서 본문과 비밀번호 해시가 제외됨
  - 잘못된 비밀번호로 열람·수정·삭제 차단
  - 올바른 비밀번호로 열람·수정·삭제 가능
  - 승인 대기 뉴스의 목록 및 직접 열람 차단
  - 관리자 외 승인·대기 목록 접근 차단
  - 관리자 검토·수정·승인 및 오래된 검토 결과의 승인 차단
  - 승인된 뉴스도 비밀번호로 보호
  - 작성자가 승인된 뉴스를 수정하면 재승인 대기로 전환
  - 공백 제목과 외부 출처 요청 차단
- 관리자 코드 등록 통합 테스트 통과.
  - 비로그인 등록 차단
  - 잘못된 코드 차단 및 올바른 코드 등록
  - 등록 후 세션 관리자 권한 확인
  - 관리자 목록에서 초대 코드 비노출
  - 자신의 관리자 권한 해제 차단
- 브라우저에서 동아리 글 등록 및 잘못된 비밀번호 오류 표시 확인.
- 브라우저에서 관리자 코드 등록 페이지와 로그인 복귀 경로 확인.
- WebMCP 탭 전환의 정상 입력과 잘못된 입력 검증.

## 관리자 설정

관리자 검증에는 로컬 개발 환경의 테스트 계정과 테스트용 코드를 사용했습니다. 운영 환경에는 별도로 생성한 초대 코드의 PBKDF2 해시와 salt를 설정하며, 초대 코드 원문은 코드와 데이터베이스에 저장하지 않습니다.

## 운영 전 확인 사항

- 최초 운영 관리자 코드 등록 및 초대 코드 보관·교체 절차 확정
- 학과 구성원의 사이트 접근 범위 확정
- 서비스 이름과 학과 이름 확정
- 통합 게시판에 모든 분류를 함께 표시하는 초기 구성 및 뉴스 수정 후 재승인 정책 검토
