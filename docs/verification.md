# 검증 기록

## 자동 검증 범위

`npm test`와 개발 서버(`npm run dev`)를 켠 상태의 `scripts/test-*.mjs`가 확인합니다.

- Firebase RS256 서명, 발급자·대상·만료·학교 이메일·이메일 인증·이름 검증
- 비회원, 위조·만료 세션과 정지 회원 차단, 로그아웃 후 세션 재사용 차단
- 게시판별 작성·목록·본문 열람·비밀번호 확인 수정·삭제, 작성자 이름과 머릿글
- 서버 검색(제목·머릿글·본문·작성자, 본문 발췌, 뉴스 제외, LIKE 특수문자 이스케이프)과 30개 단위 커서 페이지
- 댓글 작성·목록 순서·삭제 권한(본인·관리자)·뉴스 댓글 차단·목록 댓글 수
- Word 내보내기 문서 구조·파일 이름·docx 형식(`tests/news-docx.test.ts`)
- 학과 뉴스 비공개(작성자·관리자만), 관리자 수정·피드백·반려·승인, 오래된 검토 요청 차단, 재제출 시 피드백 초기화, 반려 기사 수정 차단
- 회원의 마지막 뉴스 검토 시각(`newsReviewedAt`)
- 직책(일반·학사·학생회·관리자) 지정, 자기 직책 변경 차단, 새 관리자가 기존 관리자 직책 변경, 학사·학생회의 담당 게시판 열람·답변 배지
- 회원 탈퇴와 세션 삭제, 관리자 회원 검색·정지·복구
- 피드백 표시 구간 분할·메모 번호·겹침 판정(`tests/annotations.test.ts`)
- 가입·로그인·이메일 인증·이메일 작업·비회원 안내 페이지 렌더링
- TypeScript, ESLint와 배포용 빌드

## 운영에서 확인한 항목

- [x] `@ks.ac.kr` 계정 가입, 인증 메일 수신, 로그인
- [x] 운영용 관리자 코드 등록 (Workers PBKDF2 반복 상한 10만 회에 맞춤)
- [ ] 게시글 작성·열람과 로그아웃
- [ ] 비밀번호 재설정 메일과 새 비밀번호 로그인
- [ ] 뉴스 제출 → 관리자 피드백 → 작성자 확인 → 재제출 → 승인
- [ ] 시크릿 브라우저에서 첫 화면은 열리고 게시글 정보는 보이지 않음

인증 메일 링크는 Firebase 기본 작업 화면을 거쳐 `/login`으로 돌아옵니다. 콘솔에서 사용자 지정 작업 URL 저장이 400 오류로 거부되어 `/auth/action`은 현재 쓰이지 않습니다.

## 운영 배포

- 배포 URL: `https://micom.loungee.workers.dev`
- Cloudflare Worker `micom`, D1 `micom-lounge` (`wrangler.jsonc`)
- 배포: `main` 브랜치에 합치면 GitHub Actions가 DB 변경 적용 후 배포합니다. 수동 배포는 `npm run db:migrate:remote`와 `npm run deploy`.
