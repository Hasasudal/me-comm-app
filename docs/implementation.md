# 1차 웹 구현 범위

기존 기획서의 확정 내용을 구현합니다.

- 통합 게시판, 뉴스, 동아리, 공모전 모집을 제공하는 반응형 커뮤니티입니다.
- 각 메뉴는 별도 페이지(`/`, `/news`, `/clubs`, `/contests`)로 이동하며 뉴스 승인도 `/admin`에서 제공합니다. 각 전용 게시판의 글쓰기는 해당 분류로 고정됩니다.
- 초기 통합 목록에는 모든 분류를 모으며 개별 탭에서 해당 분류만 표시합니다.
- 목록은 제목·분류·작성일만 반환하며 본문은 서버의 비밀번호 확인 후 반환합니다.
- 비밀번호는 무작위 salt와 PBKDF2 해시로 저장합니다.
- 뉴스 제출 시 승인 대기, 관리자 승인 후 공개합니다. 대기 글은 일반 API에 노출하지 않습니다.
- 승인된 뉴스를 작성자가 수정하면 재승인 대기로 전환합니다.
- 관리자 권한은 `/admin/join`에서 초대 코드를 인증한 ChatGPT 계정에 부여하며 D1의 활성 관리자 목록으로 매 요청마다 확인합니다. 초대 코드 원문은 저장하지 않고 PBKDF2 해시와 salt만 운영 환경에 둡니다.
- 활성 관리자는 등록된 관리자 목록을 확인하고 다른 관리자의 권한을 해제할 수 있습니다. 자신의 권한 해제는 차단합니다.
- 게시글은 D1에 저장합니다. 전체 회원가입, 파일 첨부, 반려, 비밀번호 복구는 이번 범위에 포함하지 않습니다.
- CRUD, 비밀번호 실패, 대기 글 비공개, 승인 권한, 모바일 화면을 검증합니다.
